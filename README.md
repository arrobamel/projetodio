### 🛠️ Como foi construído

Para garantir um dashboard leve e com carregamento rápido, a construção foi dividida em etapas:

**1. Design e Layout - Canva**
Criei a base visual e os fundos no Canva para evitar o uso excessivo de imagens pesadas dentro do Power BI. Isso deixa o `.pbix` mais leve e o carregamento mais rápido.

**2. Visualização - Power BI**
Importação dos dados e criação dos visuais nativos, com DAX para tratamento do trimestre e medidas de vendas/lucro.

**3. Apresentação**
Gravação da navegação entre as páginas e conversão para GIF otimizado (10 FPS / 600px) para demonstração fluida no README sem pesar o repositório.
