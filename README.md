# 📊 Relatório de Vendas - Desafio DIO Power BI + Azure


---

### 🎯 Sobre o Projeto

Dashboard desenvolvido para o **Desafio de Projeto da DIO - Processamento de Dados com Power BI**, utilizando base **AdventureWorks** hospedada no **Azure SQL Database**.

O objetivo foi criar uma solução completa de BI: desde a conexão com a nuvem, tratamento com Power Query, modelagem em estrela, criação de medidas DAX até storytelling visual.

### 📑 As 3 Páginas

#### 📌 Página 1 - Relatório de Vendas
> Visão executiva geral
- **💰 118,73 MI** Total de Vendas (+12,4% vs 2022)
- **📦 1,13 MI** Unidades Vendidas (+8,1% vs 2022)
